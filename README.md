# For Shaila

A single-page Valentine’s letter inspired by the look in the screenshot. Open the page in a browser to view the full layout and scroll animation.

## What's inside

- `index.html` — the main page content and letter text.
- `styles.css` — styling for the hero banner and the letter card.

## How to view

Open `index.html` directly in your browser or use VS Code's Live Server if you prefer.
